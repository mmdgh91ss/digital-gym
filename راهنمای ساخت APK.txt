# پروژه اندروید باشگاه دیجیتال

این پروژه، فایل HTML ارسالی شما را در یک WebView اندرویدی اجرا می‌کند.

## ساخت APK با Android Studio
1. Android Studio را نصب و اجرا کنید.
2. از مسیر **File > Open** پوشه `DigitalGymAndroid` را انتخاب کنید.
3. صبر کنید Gradle Sync کامل شود و در صورت درخواست، Android SDK 35 را نصب کنید.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** را انتخاب کنید.
5. پس از پایان ساخت، روی **locate** کلیک کنید. فایل خروجی معمولاً در مسیر زیر است:
   `app/build/outputs/apk/debug/app-debug.apk`

## نکته‌ها
- نام برنامه: باشگاه دیجیتال
- شناسه برنامه: `com.digitalgym.app`
- حداقل نسخه اندروید: Android 6.0 (API 23)
- برای دریافت فهرست حرکات و GIFها اتصال اینترنت لازم است؛ چون سایت اصلی داده‌ها را از CDN و API بیرونی می‌گیرد.
- این پوشه، پروژه آماده ساخت است و خودش فایل APK کامپایل‌شده نیست.
